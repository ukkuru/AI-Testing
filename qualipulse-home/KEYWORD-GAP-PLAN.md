## 4. Rules for every update
- One primary keyword per URL. Put it in the title, the H1, the first 100 words and one H2.
- Every update adds something new: a table, a number from a real case study, or a first-hand example. Swapping words alone does not move rankings.
- Never invent numbers. Use only the case study data you have.
- Link every new post to one service page and one case study.

## 5. What will actually decide this
The keywords are winnable on difficulty, but the site has only about 6 real referring domains. Animalz, Omniscient and Grow and Convert each have thousands. Content updates get you indexed and relevant. The backlink plan gets you onto page one: speaker pages, QA publications, the Page Pulse tool and podcasts. Run both in parallel.
