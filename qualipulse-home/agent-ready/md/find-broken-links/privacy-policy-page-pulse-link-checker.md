# Privacy Policy: Page Pulse Link Checker

Last updated: 9 October 2026  
Publisher: QualiPulse

Page Pulse Link Checker (“the extension”) is a Chrome extension that scans the links on a webpage you choose to check and reports which ones work, redirect, or are broken. This policy describes exactly what the extension does with your data.

## Summary

- No account, signup, or login is required or offered.
- There is no QualiPulse server or backend. The extension does not transmit your browsing activity, scan results, or settings to QualiPulse or to any third party.
- Nothing runs until you click “Scan Links.” The extension does not scan, track, or monitor pages in the background.
- All data the extension stores lives only in your local Chrome profile, never in the cloud.

## What the Extension Does

When you open a webpage and click “Scan Links,” the extension:

- Reads the links present on that page.
- With your permission, sends standard web requests to each linked destination to check whether it works. These are the same kind of requests your browser sends when you visit a page.
- Shows the results directly on the page and in the extension popup: Working, Broken, Redirected, or Unable to verify.
- Lets you export those results to a CSV or JSON file saved to your own computer.

## Data the Extension Does Not Collect

The extension does not collect, read, or transmit:

- Passwords, cookies, form entries, or authentication tokens.
- Browsing history beyond the single page you explicitly scan.
- Any personally identifying information about you.
- Analytics, telemetry, or usage statistics of any kind.

There is no analytics SDK, tracking pixel, or third party data collection library in the extension.

## Data Stored Locally on Your Device

The extension stores the following locally, in a storage area private to your browser profile that only the extension itself can read:

- **Preferences:** Your chosen highlight style, enabled status categories, timeout, and concurrency settings.
- **Scan results:** The most recent scan’s findings for each tab you have scanned, so the extension popup shows a consistent state if you close and reopen it.

This data is never uploaded anywhere. You can delete it at any time using the “Clear Local Data” button in the extension popup. It is also removed automatically when you navigate away from a scanned page or uninstall the extension.

## Network Requests to the Sites You Scan

To check whether a link works, the extension must send a request to that link’s destination. There is no way to verify a link without contacting it.

This means:

- The destination website will see a normal web request, including your IP address, exactly as it would if you had visited that link yourself in your browser.
- These requests only go to links found on the page you explicitly chose to scan, and only when you click “Scan Links.” They never run automatically or in the background.
- The extension does not attempt to bypass logins, CAPTCHAs, or other access restrictions. If a site blocks or restricts the request, the extension reports that link as “Unable to verify” rather than guessing its status.

## Permissions This Extension Requests and Why

| Permission | Purpose |
| --- | --- |
| Active Tab | Lets the extension read links on the page you are currently viewing, only after you click the extension icon. |
| Scripting | Lets the extension extract links from the page and draw the colored status highlights on it. |
| Storage | Saves your preferences and recent scan results locally, as described above. |
| Downloads | Saves the CSV or JSON report you export to a file on your computer. |
| Host access: all HTTP and HTTPS sites | Requested at runtime, only when you click “Scan Links,” and only used to check the status of links found on the page you are scanning. |

You can decline host access. The extension will still run, but link status checks will show “Unable to verify” instead of a confirmed result.

## Data Sharing

QualiPulse does not sell, rent, or share any data collected by this extension with third parties because no data is collected by QualiPulse in the first place. Everything described above stays on your device.

## Children’s Privacy

This extension is a general purpose developer and SEO tool and is not directed at children. It does not knowingly collect any information from children.
